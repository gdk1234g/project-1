# ATLDSD 实验材料：发布整理副本

## 阅读顺序

先阅读 [实验汇总](EXPERIMENT_SUMMARY.md) 和 [清理说明](PUBLICATION_REVIEW.md)。

- `training_summary.csv`：由每份实际 history 计算的最佳验证轮次、指标和留存情况。
- `run_index.json` 与 `runs/`：训练参数、数值历史、整理后的日志、真实训练配置快照（存在时）和包版本。
- `metric_index.json` 与 `metrics/`：聚合验证/测试指标和逐类别 CSV。
- `document_index.json` 与 `notes/`：实验过程、失败实验、阶段结论及标注局限的历史记录。
- `configs/`：原项目中的参数配置。路径已改成通用本地路径。

## 范围与整理方法

详细实验材料仅包括 ATLDSD 实验；汇总末尾另附外部数据混合训练的简短文字说明，不提供该尝试的实验附件。`mix_w02` 表示 CE+Dice+0.2×Tversky 的混合损失，不表示加入其他数据集。
原始实验值保持不变；CSV 仅统一编码和换行。相同副本合并，内容不同的旧记录保留；日志只保留数值训练过程、早停与退出状态。原日志中的启动命令、路径、警告和非训练输出没有完整保留，故整理日志不能代替原始日志。空日志和占位日志没有伪造成真实记录。
各实验目录中的 `publication_notes.json` 说明日志和配置留存情况。旧 seed45 的占位日志未发布，相应配置副本标为 `unverified_config_copy.json`，不称为已验证的训练快照。仓库顶层历史参数配置不是缺失运行快照的替代品。

本副本不包含数据集图片、标注、逐样本清单、逐图错例表、模型权重、压缩归档或完整系统环境转储。只有包名与版本被提取。没有逐项数据清单，使用者自行重建划分时不保证与历史实验逐样本一致。当前发布代码经过适配，不是原训练时源码的逐字节快照。

## 结果解读

以训练 history 计算的最佳指标和独立重新评估指标分开报告，设备/评估方式差异可能导致小幅数值差异。旧 seed45 与 seed45_complete 是不同运行，不能混为一轮。缺少证据的参数和随机种子不根据目录名补写。
现有文档中的建议是历史阶段记录；当前 ATLDSD 基线已冻结。seed46 256 的验证指标约为 mIoU 0.7357、mDice 0.8358，不能解释为全体历史实验中的唯一最佳或田间泛化证明。
历史测试集曾被查看，不应将其描述为后续完全未触碰的测试集。新增实验选型使用验证集，并清楚报告测试集使用情况。
`legacy_finetune_evaluation` 是旧微调权重的 epoch 53 测试报告，当前未找到对应训练 history；该报告保留原数值和未确认的训练来源状态，不归入 seed46 候选表现。指标报告中的 `publication_notes` 标明是否能对应到本目录的训练记录。
